# UI kit tokens

The TypeScript files in `tokens/` are the source of truth. Base tokens define
shared values, theme tokens define semantic colours, and component tokens define
control roles. Update the appropriate source file and run:

```sh
npm run build:tokens
npm run build
```

`styles/theme.css` is generated by `scripts/token-css.ts`. The Button component
and its styles are copied from Forme's portable Aero kit; the playground owns
this copy and can customise its tokens without changing the workbench.
